# Saxon Math K–5

本目录的材料改编自 HMH（Houghton Mifflin Harcourt）出版的 Saxon Math 小学系列：幼儿园到二年级为 Saxon Math K、1、2（Nancy Larson 编），三到五年级为 Saxon Math Intermediate 3、4、5（Stephen Hake 编，© 2008 Harcourt Achieve）。Saxon 是螺旋式编排，每 10 课左右为一个部分（Section），中高年级每部分末尾还有一个探究（Investigation）。

- [各年级大纲与完整课次表（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源与核对情况见大纲开头：三、四年级课题逐字摘自学生用书目录；五年级和 K–2 的课题来自公开的第三方课次列表（IXL 对齐文件等），**标为待核**。
