# FOSS 小学科学 K–5

本目录的材料改编自 FOSS（Full Option Science System）小学科学课程：加州大学伯克利分校劳伦斯科学馆（Lawrence Hall of Science）研发，School Specialty / Delta Education 出版。采用的版本是 **FOSS Next Generation（©2018–19，NGSS 版）**，每个年级 3 个模块（物质科学、地球科学、生命科学），模块下分探究（Investigation），探究下分部分（Part）。

- [各年级大纲与完整的探究、部分列表（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源与核对情况见大纲开头：部分标题来自 Delta 官方的 Next Generation / Pathways 目录对照表和劳伦斯科学馆的官方文件；四年级《环境》和五年级《生命系统》有少量标题**待核**。

## 海报
