# Elevate Science 小学科学 K–5

本目录的材料改编自 Savvas Learning Company（原 Pearson 培生）出版的 Elevate Science 小学科学课程，按 **Elevate Science ©2019 全国版（NGSS）** 整理。Elevate Science 是 Scott Foresman Science 的后继教材，旧版的大纲和海报见 [Scott Foresman Science](<../Scott Foresman Science>)。

年级和主题（Topic）、每个主题的项目式任务 Quest 取自 Savvas 官方 K–8 范围与顺序表；各课课名取自第三方 IXL 技能计划，并用 Savvas 官方佐治亚州版关联表逐一核对；实验名称（uConnect / uInvestigate / uDemonstrate / Quest Check-In Lab）取自 Savvas 官方佐治亚州版关联表，对应回全国版的课。来源链接、核实情况和待核事项见大纲。

- [各年级大纲与完整的课程列表（Markdown）](大纲.md) · [PDF](大纲.pdf)

## 海报

全套 42 个主题、139 课。课数不超过 250，所以每课一张海报，共 139 张。已完成 20 张（PNG + PDF），其中教材活动 5 张、示例探究 15 张。每张海报分 01 现象、02 探究、03 结论三行，小结框有拓展和安全提示，底部标注教材来源。「教材活动」表示第 02 行画的是官方公开了名称的实验（英文名写在海报上；步骤没有公开，注明步骤为示意）；「示例探究」表示找不到这一课的官方实验名，海报改用本项目设计的探究。海报只用公制单位和人民币，自己举的数量标「示例」，器材画成示意。
