# Mystery Science 小学科学 K–5

本目录的材料改编自 Mystery Science（mysteryscience.com，2020 年起属于 Discovery Education）小学科学课程，面向 NGSS。单元、谜题、问题和动手活动取自 **mysteryscience.com 官网当前在线版本（2026-10-17 访问）**。每个年级 5–6 个单元，每个单元由几个“谜题”（Mystery）组成，每个谜题是一节课：一个问题 + 一个动手活动。

- [各年级大纲与完整的谜题列表（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源、版本说明和待核事项见大纲开头。

## 海报
