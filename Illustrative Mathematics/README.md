# Illustrative Mathematics K–5

本目录的材料改编自 IM K–5 Math™ v.1（Illustrative Mathematics，2021 年开放版本，CC BY 4.0，由 Kendall Hunt 平台发布），覆盖幼儿园到五年级。每个年级有 8–9 个单元，每个单元分成 2–4 个部分（Section）。

- [各年级大纲与知识点（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源：[IM K–5 Math 课程页](https://curriculum.illustrativemathematics.org/k5/curriculum.html) · 各年级 Course Guide 里的 Scope and Sequence 页面，例如 [三年级](https://curriculum.illustrativemathematics.org/k5/teachers/grade-3/course-guide/scope-and-sequence.html)（大纲里列出了全部链接）
