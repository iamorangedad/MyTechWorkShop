# OpenSciEd 初中科学 6–8

本目录的材料改编自 [OpenSciEd](https://www.openscied.org/access-the-materials/) 初中科学课程（Middle School，免费开放教育资源，对齐 NGSS），按官网现行的初中第一版整理。OpenSciEd 课程以 CC BY 4.0 授权（见[使用条款](https://openscied.org/openscied-terms-of-use-and-privacy-policies/)），本目录的大纲和海报是改编译写，署名 OpenSciEd。

六、七、八年级各 6 个单元，共 18 个单元、269 课。单元名、单元问题取自官方单元页；每课的课题问题、类型、现象和探究取自各单元官方公开的 Unit Storyline（单元故事线）PDF。来源链接和待核事项见大纲。

- [大纲：18 个单元、269 课的完整列表（Markdown）](大纲.md) · [PDF](大纲.pdf)

## 海报

共 269 课，超过 250，所以按「每个课级探究一张」出海报：故事线类型里含锚定现象或探究的课各一张，共 195 张；只有整合 / 提出新问题的课只列在大纲里。已完成 131 张（PNG + PDF）：六年级 67、七年级 64、八年级 0。每张海报分 01 现象、02 探究、03 结论三行：02 行画的是故事线里这一课的真实探究（步骤按故事线描述画成示意），03 行是故事线里「我们弄明白」的要点；小结框有拓展和安全提示，底部标注教材来源。海报只用公制单位和人民币；故事线没有给出的数量不编造，为说明而举的数字标「示例」。
