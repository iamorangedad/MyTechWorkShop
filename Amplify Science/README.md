# Amplify Science 小学科学 K–5

本目录的材料改编自 Amplify Science 小学科学课程：由加州大学伯克利分校劳伦斯科学馆（Lawrence Hall of Science）与 Amplify 合作研发，面向 NGSS。章、课标题取自 **Amplify Science California（加州版）K–5 单元指南（©2021）**；单元与全国版相同。每个年级 3–4 个单元，单元下分章（Chapter），章下分课（Lesson），每个单元围绕一个角色和锚定现象展开。

- [各年级大纲与完整的章、课列表（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源、版本差异和待核事项见大纲开头。

## 海报

全套 21 个单元、89 章、466 课。章数不超过 250，所以每章一张海报，共 89 张。已完成 57 张（PNG + PDF）。每张海报用 01/02/03… 几步画出这一章的锚定问题和关键课（标注课号），底部标注教材来源。海报只用公制单位和人民币，自己举的数量标「示例」，器材画成示意，需要注意安全的地方写在小结框里。
