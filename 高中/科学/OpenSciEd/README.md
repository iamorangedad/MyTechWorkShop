## 海报

共 201 课，不超过 250，所以每课一张海报，共 201 张，按学科放在 `海报/生物/`、`海报/化学/`、`海报/物理/`。已完成 0 张（PNG + PDF）：生物 0、化学 0、物理 0。每张海报分 01 现象、02 探究或活动、03 结论三行：02 行画的是故事线里这一课的真实做法（步骤按故事线描述画成示意），03 行是故事线里「我们弄明白」的要点；小结框有拓展和安全提示，底部标注教材来源。海报只用公制单位和人民币；故事线没有给出的数量不编造，为说明而举的数字标「示例」。化学实验的浓度和用量以教师用书和学校实验室安全规定为准。
